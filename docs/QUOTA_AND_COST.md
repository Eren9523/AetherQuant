# AetherQuant 存储配额与成本管控白皮书 (Quota & Cost Controls)

## 1. 8GB 存储安全熔断策略 (Rule 15-25)

AetherQuant 设置了绝对物理安全上限 **8GB**，按四级状态机实时流转：

| 状态 | 占用容量 | 系统行为与控制动作 |
| :--- | :--- | :--- |
| **NORMAL (正常)** | `< 6 GB` | 所有上传、回测与报告生成全功能正常可用 |
| **WARNING (预警)** | `6 GB - 7 GB` | 界面顶部展示存储预警 Banner，提示用户清理临时数据 |
| **RESTRICTED (受限)** | `7 GB - 8 GB` | 暂停普通用户临时数据上传，仅允许关键回测配置与永久数据集写入 |
| **READ_ONLY (只读)** | `≥ 8 GB` | **立即触发存储熔断**，全平台进入只读状态，拒绝任何写入并执行紧急清理 |

## 2. 免费层级用量限制 (Free Tier Policy)
- **AI 智能交互**：每日限 3 次完整分析调用，每月 Token 预算保障系统安全运行。
- **策略回测执行**：每日限 3 次完整日频仿真回测。
- **文件与数据集**：单文件最大 `10 MB`，每日上传最大 `30 MB`，临时数据保留 `7-14 天`。
- **策略与自选股**：最多创建 20 个策略，自选股上限 100 支。

## 3. 全局成本防护 (Global Budget Guard)
- 平台设置每月 DeepSeek API 全局预算上限 `$50.00`。
- 达到 80% 触发管理员预警，达到 100% 自动切换至内置量化逻辑引擎，防止账单超支。
