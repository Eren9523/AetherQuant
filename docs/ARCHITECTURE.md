# Penguin Quant 架构设计文档 (Architecture Document)

## 1. 总体架构拓扑 (Overall Architecture)

Penguin Quant 采用现代分层量化系统设计，划分为客户端表现层、边缘与网关路由层、量化核心计算层、以及分布式数据持久化层：

```
+-------------------------------------------------------------------------+
|                  React 18 + Tailwind SPA (Client Workspace)              |
|   - 仪表盘 (Overview)        - 行情中心 (AKShare)      - 因子实验室 (Barra) |
|   - 策略引擎 (DSL Builder)   - 严格回测中心 (T+1)      - DeepSeek AI Copilot|
+-------------------------------------------------------------------------+
                                    │
                                    │ HTTP / SSE Stream
                                    ▼
+-------------------------------------------------------------------------+
|                API Gateway & Orchestrator (Node.js / Worker)            |
|   - 鉴权与配额断路器 (Usage & Quotas 8GB Safety Guard)                   |
|   - 数据流缓存与降级层 (In-Memory + File/D1 Cache)                        |
|   - DeepSeek SSE 代理与 Function Calling 调度器                         |
+-------------------------------------------------------------------------+
             │                                              │
             ▼                                              ▼
+-----------------------------+               +---------------------------+
| Cloudflare D1 (SQLite)      |               | Cloudflare R2 (Storage)   |
| - 资产标的表 (instruments)  |               | - 结构化数据 (datasets)   |
| - 因子定义表 (factors)      |               | - 研报与财报 (documents)  |

+-------------------------------------------------------------------------+
```

## 2. 核心模块说明

1. **API 网关 (`/api/v1/*`)**:
   - 统一处理行情、因子、回测、仿真交易、AI 交互与配额监控。
   - 内置 8GB 存储安全熔断与日频调用配额保护。
2. **数据质量与合规引擎 (`DataQualityEngine`)**:
   - 检验行情数据的高低价关系、换手率异常、缺失值与时间戳重复。
3. **因子计算引擎 (`FactorEngine`)**:
   - 提供动量 (MOM)、波动率 (VOL)、流动性 (TURN)、技术指标 (RSI/MA) 及五分位单调性测试。
4. **策略仿真与回测引擎 (`BacktestEngine`)**:
   - 严守 A 股交易制度：100股整数倍、T+1可卖限制、卖出单边 0.05% 印花税、双边 0.03% 佣金与 0.05% 滑点。
